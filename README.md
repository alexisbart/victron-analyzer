# Victron Analytics

Application Streamlit permettant d'analyser les exports avancés VRM Victron.

## Fonctionnalités

- Upload Excel VRM
- Détection automatique des mesures
- Sélection des courbes
- Zoom interactif Plotly
- Filtrage temporel

## Installation

```bash
pip install -r requirements.txt
```

## Lancement

```bash
streamlit run app.py
```
